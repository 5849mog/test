# 郑老师中考倒计时

Windows 桌面壁纸程序：每天自动生成带完整课表、一模倒计时和中考倒计时的壁纸。

## 使用方法

1. 先把 `郑老师中考倒计时.exe` 复制到希沃电脑上的固定位置（例如桌面上的专用文件夹），不要直接从 U 盘运行。
2. 双击 `郑老师中考倒计时.exe`。
3. 程序会立即设置壁纸并自动启用开机启动。
4. 右键任务栏右下角的酒红色“稳”图标，点击唯一的“启动设置”入口，可以统一管理底图、课表位置、开机启动和原壁纸恢复。

更换底图只会改变最底层图片。课表、酒红色倒计时区域、日期、字体和排版均由程序固定绘制，不会被替换。

推荐使用 16:9 横向图片作为底图。图片分辨率至少为 640×360，建议不低于 1920×1080。

## 固定日期

- 一模：2027 年 1 月 12 日
- 中考：2027 年 6 月 19 日

程序在启动时、日期变化后以及屏幕分辨率变化后自动重新生成壁纸。

课表水平位置以屏幕宽度百分比保存，因此换到不同分辨率的电脑仍会按比例保持位置。可移动范围为屏幕左侧 3%–25%，右侧酒红倒计时区域不会移动。

右侧倒计时会显示按日期推进的备考进度条和本机 `HH:mm` 实时时间；程序每 15 秒检查一次，只在分钟变化时更新壁纸。工作日当天的星期列会以酒红色胶囊和亮色文字提示；当前正在进行的课程单元格会用浅金填充和细金边框直接框出；激励语共 10 句，按日期自动轮换。

## Wallpaper Engine 与未激活 Windows

- 如果电脑正在运行 Wallpaper Engine，它会覆盖 Windows 的静态壁纸层。此时“个性化”页面可能已经显示倒计时壁纸，但桌面仍显示 Wallpaper Engine 的动态壁纸。
- 临时暂停或退出 Wallpaper Engine 后，就能看到本程序设置的壁纸。
- Windows 未激活主要限制系统“个性化”界面的部分操作，不会阻止本程序或 Wallpaper Engine 通过系统接口更换壁纸。
- 希沃电脑如果没有安装 Wallpaper Engine，不会遇到这一层覆盖。
